# OF-403 — Titre ou description de page manquant

- Gravité : **erreur**
- Niveau de contrôle : build (avant livraison)
- Statut : appliquée

## Pourquoi

`<title>` et la meta description sont affichés par les moteurs de recherche.

## Comment corriger

Utilisez `generateMetadata` de `createOpenFlowPage()` et remplissez `seo.title` et `seo.description` dans le contenu de départ de chaque page.

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-403` au-dessus de la ligne, ou `/* openflow-disable OF-403 */` pour tout le fichier. Expliquez pourquoi en commentaire.

# OF-203 — Configuration OpenFlow invalide

- Gravité : **erreur**
- Niveau de contrôle : rendu (fin de tâche)
- Statut : appliquée

## Pourquoi

`openflow.config.tsx` est partagé par le site public et l'admin ; une erreur empêche l'un ou l'autre de fonctionner.

## Comment corriger

Utilisez `defineConfig({ site: { name, lang }, components, settings })`, des noms de sections en PascalCase, et des catégories qui référencent des sections existantes.

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-203` au-dessus de la ligne, ou `/* openflow-disable OF-203 */` pour tout le fichier. Expliquez pourquoi en commentaire.

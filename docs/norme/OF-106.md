# OF-106 — Texte affiché mais non éditable directement sur la page

- Gravité : **avertissement**
- Niveau de contrôle : rendu (fin de tâche)
- Statut : appliquée

## Pourquoi

Un non-technicien s'attend à cliquer sur un texte pour le modifier (comme dans Webflow ou Framer). Sans `contentEditable`, il doit passer par le panneau latéral.

## Comment corriger

Ajoutez `contentEditable: true` aux champs `text` et `textarea` affichés comme contenu d'un élément. Ne le faites pas pour les champs utilisés dans un attribut (voir OF-108).

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-106` au-dessus de la ligne, ou `/* openflow-disable OF-106 */` pour tout le fichier. Expliquez pourquoi en commentaire.

# OF-105 — Champ sans valeur par défaut

- Gravité : **erreur**
- Niveau de contrôle : rendu (fin de tâche)
- Statut : appliquée

## Pourquoi

Quand le propriétaire ajoute une section, Puck utilise `defaultProps`. Sans valeur par défaut, la section apparaît vide ou plante.

## Comment corriger

Ajoutez chaque champ dans `defaultProps` avec un contenu d'exemple réaliste. Pour une liste, ajoutez aussi `defaultItemProps`. Une image ou un lien peuvent valoir `null`.

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-105` au-dessus de la ligne, ou `/* openflow-disable OF-105 */` pour tout le fichier. Expliquez pourquoi en commentaire.

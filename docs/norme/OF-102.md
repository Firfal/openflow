# OF-102 — Image écrite en dur au lieu d'un champ image

- Gravité : **erreur**
- Niveau de contrôle : rapide (à chaque modification)
- Statut : appliquée

## Pourquoi

Une image importée ou référencée par une URL fixe ne peut pas être remplacée depuis la médiathèque OpenFlow.

## Comment corriger

Déclarez `image: imageField({ label: "Image" })` (import depuis `@openflow/core`), mettez `image: null` ou une image d'exemple dans `defaultProps`, puis affichez-la avec `imageProps(image)` : `{image?.src && <img {...imageProps(image)!} />}`.

## À éviter

```tsx
import hero from "./hero.jpg";
render: () => <img src={hero.src} alt="Boulangerie" />
```

## À faire

```tsx
fields: { image: imageField({ label: "Photo" }) },
defaultProps: { image: null },
render: ({ image }) => {
  const img = imageProps(image);
  return img ? <img {...img} /> : null;
}
```

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-102` au-dessus de la ligne, ou `/* openflow-disable OF-102 */` pour tout le fichier. Expliquez pourquoi en commentaire.

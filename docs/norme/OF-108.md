# OF-108 — Champ `contentEditable` utilisé dans un attribut ou une chaîne

- Gravité : **erreur**
- Niveau de contrôle : rendu (fin de tâche)
- Statut : appliquée

## Pourquoi

Dans l'éditeur, un champ `contentEditable` est transformé en élément React éditable. Utilisé dans un attribut (`alt`, `title`, `aria-label`) ou concaténé, il devient « [object Object] ».

## Comment corriger

Retirez `contentEditable` de ce champ, ou utilisez un second champ non éditable en ligne pour l'attribut.

## À éviter

```tsx
title: { type: "text", contentEditable: true }
render: ({ title }) => <img alt={title} ... />
```

## À faire

```tsx
title: { type: "text" }
render: ({ title }) => <img alt={title} ... />
```

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-108` au-dessus de la ligne, ou `/* openflow-disable OF-108 */` pour tout le fichier. Expliquez pourquoi en commentaire.

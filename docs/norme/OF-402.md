# OF-402 — Hiérarchie de titres incorrecte

- Gravité : **avertissement**
- Niveau de contrôle : build (avant livraison)
- Statut : appliquée

## Pourquoi

Une page doit avoir un seul `h1`, et les niveaux ne doivent pas sauter (h2 → h4). C'est important pour le référencement et l'accessibilité.

## Comment corriger

Réservez `h1` à la section d'en-tête de page (par exemple le Hero), et utilisez `h2` puis `h3` dans les autres sections.

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-402` au-dessus de la ligne, ou `/* openflow-disable OF-402 */` pour tout le fichier. Expliquez pourquoi en commentaire.

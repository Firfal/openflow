# OF-405 — Langue de la page non déclarée

- Gravité : **erreur**
- Niveau de contrôle : build (avant livraison)
- Statut : appliquée

## Pourquoi

`<html lang>` est nécessaire aux lecteurs d'écran et aux moteurs de recherche.

## Comment corriger

Dans `app/layout.tsx`, utilisez `<html lang={getSite().lang}>`.

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-405` au-dessus de la ligne, ou `/* openflow-disable OF-405 */` pour tout le fichier. Expliquez pourquoi en commentaire.

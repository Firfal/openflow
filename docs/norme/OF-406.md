# OF-406 — Élément interactif sans nom accessible

- Gravité : **erreur**
- Niveau de contrôle : build (avant livraison)
- Statut : appliquée

## Pourquoi

Un lien, un bouton ou un champ sans nom est muet pour les lecteurs d'écran, et les agents IA qui naviguent pour le visiteur (Claude, ChatGPT, Gemini) ne savent pas à quoi il sert : ils lisent l'arbre d'accessibilité comme un lecteur d'écran.

## Comment corriger

Donnez un texte visible au lien ou au bouton ; pour une icône seule, ajoutez `aria-label` (« Ouvrir le menu »). Associez chaque champ à un `<label>` (`htmlFor` et `id`, ou le champ dans le label). Une `<iframe>` prend un `title`.

## À éviter

```tsx
<button onClick={open}><MenuIcon /></button>
<input type="email" placeholder="E-mail" />
```

## À faire

```tsx
<button onClick={open} aria-label="Ouvrir le menu"><MenuIcon aria-hidden /></button>
<label htmlFor="email">E-mail</label><input id="email" type="email" />
```

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-406` au-dessus de la ligne, ou `/* openflow-disable OF-406 */` pour tout le fichier. Expliquez pourquoi en commentaire.

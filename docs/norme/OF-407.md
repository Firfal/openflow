# OF-407 — Élément cliquable non natif

- Gravité : **avertissement**
- Niveau de contrôle : build (avant livraison)
- Statut : appliquée

## Pourquoi

Un `div` ou un `span` rendu cliquable (`role="button"`, `tabindex`, `onclick`) échappe au clavier et aux agents IA, qui cherchent des liens et des boutons natifs pour agir.

## Comment corriger

Utilisez `<a href>` pour aller vers une page et `<button type="button">` pour une action, stylés comme vous le souhaitez.

## À éviter

```tsx
<div role="button" tabIndex={0} onClick={open}>Voir la carte</div>
```

## À faire

```tsx
<button type="button" onClick={open}>Voir la carte</button>
```

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-407` au-dessus de la ligne, ou `/* openflow-disable OF-407 */` pour tout le fichier. Expliquez pourquoi en commentaire.

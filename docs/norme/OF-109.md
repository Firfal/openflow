# OF-109 — Champ éditable invisible dans l'éditeur

- Gravité : **avertissement**
- Niveau de contrôle : rendu (fin de tâche)
- Statut : appliquée

## Pourquoi

Le propriétaire modifie les textes directement sur la page. Un champ affiché seulement dans un état caché (`hidden`, `invisible`, `opacity-0`, `sr-only`, une animation, un très grand écran) ne peut pas être cliqué dans l'éditeur : il n'est modifiable qu'en cherchant dans le panneau latéral.

## Comment corriger

Quand `puck?.isEditing` est vrai, affichez ce champ dans un élément visible (par exemple une ligne « coulisses » sous la section qui liste les textes des états cachés), ou montrez l'état qui le contient. Les éléments `<details>` n'ont pas besoin d'être modifiés : l'éditeur les ouvre.

## À éviter

```tsx
render: ({ savedLabel }) => <span className="opacity-0">{savedLabel}</span>
```

## À faire

```tsx
render: ({ savedLabel, puck }) => (
  <>
    <span className="opacity-0">{savedLabel}</span>
    {puck?.isEditing && <span className="chip">{savedLabel}</span>}
  </>
)
```

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-109` au-dessus de la ligne, ou `/* openflow-disable OF-109 */` pour tout le fichier. Expliquez pourquoi en commentaire.

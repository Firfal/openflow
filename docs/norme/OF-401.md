# OF-401 — Image sans attribut alt

- Gravité : **erreur**
- Niveau de contrôle : build (avant livraison)
- Statut : appliquée

## Pourquoi

Accessibilité (lecteurs d'écran) et référencement.

## Comment corriger

Affichez l'image avec `imageProps(image)`, qui fournit toujours `alt`. Pour une image décorative codée en dur, utilisez `alt=""`.

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-401` au-dessus de la ligne, ou `/* openflow-disable OF-401 */` pour tout le fichier. Expliquez pourquoi en commentaire.

# OF-111 — Image ou vidéo affichée sans `imageProps` / `videoProps`

- Gravité : **avertissement**
- Niveau de contrôle : rendu (fin de tâche)
- Statut : appliquée

## Pourquoi

`imageProps(image)` ajoute le marqueur qui permet au propriétaire de cliquer sur l'image dans l'éditeur pour la remplacer. Une image affichée avec `src={image.src}` n'est pas sélectionnable sur la page.

## Comment corriger

Affichez l'image avec `const img = imageProps(image); img && <img {...img} className="…" />`.

## À éviter

```tsx
<img src={image?.src} alt={image?.alt} />
```

## À faire

```tsx
const img = imageProps(image);
return img && <img {...img} className="rounded-xl" />;
```

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-111` au-dessus de la ligne, ou `/* openflow-disable OF-111 */` pour tout le fichier. Expliquez pourquoi en commentaire.

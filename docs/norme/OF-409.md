# OF-409 — Image sans dimensions

- Gravité : **avertissement**
- Niveau de contrôle : build (avant livraison)
- Statut : appliquée

## Pourquoi

Sans `width` et `height` (ou un ratio CSS), la page bouge pendant le chargement : mauvais pour les visiteurs (CLS, Core Web Vitals) et pour les agents IA, qui cliquent à côté quand la mise en page se décale.

## Comment corriger

Affichez les images avec `imageProps(image)`, qui fournit `width` et `height`. Pour une image codée en dur, donnez `width` et `height`, ou une classe de ratio (`aspect-[4/3]`).

## À éviter

```tsx
<img src="/logo.png" alt="Logo" />
```

## À faire

```tsx
<img src="/logo.png" alt="Logo" width={160} height={40} />
```

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-409` au-dessus de la ligne, ou `/* openflow-disable OF-409 */` pour tout le fichier. Expliquez pourquoi en commentaire.

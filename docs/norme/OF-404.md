# OF-404 — Lien interne cassé

- Gravité : **erreur**
- Niveau de contrôle : build (avant livraison)
- Statut : appliquée

## Pourquoi

Un lien vers une page inexistante produit une erreur 404.

## Comment corriger

Utilisez un champ lien de type page (`{ "kind": "page", "pageId": "…" }`), qui est recalculé à chaque publication.

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-404` au-dessus de la ligne, ou `/* openflow-disable OF-404 */` pour tout le fichier. Expliquez pourquoi en commentaire.

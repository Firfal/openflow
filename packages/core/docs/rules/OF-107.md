# OF-107 — Section qui plante avec des valeurs limites

- Gravité : **erreur**
- Niveau de contrôle : rendu (fin de tâche)
- Statut : appliquée

## Pourquoi

Le propriétaire videra des champs, collera de longs textes et supprimera des images. Une section qui plante casse la page entière dans l'éditeur et à la publication.

## Comment corriger

Protégez le rendu : `image?.src`, `items?.map(...)`, pas d'accès à une propriété d'une valeur potentiellement `null`, pas de dépendance au navigateur (`window`, `document`) pendant le rendu.

## À éviter

```tsx
render: ({ image, items }) => <><img src={image.src} />{items.map(...)}</>
```

## À faire

```tsx
render: ({ image, items }) => <>{image?.src && <img {...imageProps(image)!} />}{items?.map(...)}</>
```

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-107` au-dessus de la ligne, ou `/* openflow-disable OF-107 */` pour tout le fichier. Expliquez pourquoi en commentaire.

# OF-301 — API incompatible avec l'export statique

- Gravité : **erreur**
- Niveau de contrôle : rapide (à chaque modification)
- Statut : appliquée

## Pourquoi

Le site est publié en HTML statique sur Firebase Hosting (`output: "export"`) : il n'y a pas de serveur Next.js en production.

## Comment corriger

Supprimez l'usage de `next/headers` (`cookies()`, `headers()`), des Server Actions (`"use server"`), du middleware ou proxy, de `dynamic = "force-dynamic"`, de `revalidate` et de `dynamicParams = true`. Gardez `output: "export"` et `images.unoptimized: true` dans `next.config.ts`. Les redirections vont dans `firebase.json`.

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-301` au-dessus de la ligne, ou `/* openflow-disable OF-301 */` pour tout le fichier. Expliquez pourquoi en commentaire.

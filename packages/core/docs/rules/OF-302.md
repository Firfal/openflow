# OF-302 — Lecture de Firebase depuis le rendu public

- Gravité : **erreur**
- Niveau de contrôle : rapide (à chaque modification)
- Statut : appliquée

## Pourquoi

Le contenu publié vient du snapshot figé au moment de « Publier ». Lire Firestore depuis une page publique montrerait les brouillons, exposerait les données, et les règles de sécurité le bloquent de toute façon.

## Comment corriger

Lisez le contenu via les props des sections, et les réglages via `getSettings()` de `@openflow/next`. Seul `app/admin` utilise Firebase (via `@openflow/admin`).

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-302` au-dessus de la ligne, ou `/* openflow-disable OF-302 */` pour tout le fichier. Expliquez pourquoi en commentaire.

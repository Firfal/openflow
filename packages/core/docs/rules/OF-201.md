# OF-201 — Contenu non conforme au schéma

- Gravité : **erreur**
- Niveau de contrôle : rendu (fin de tâche)
- Statut : appliquée

## Pourquoi

Le contenu de départ (`openflow/seed`) est importé dans Firestore à la livraison. S'il ne correspond pas aux champs déclarés, l'éditeur affichera des valeurs vides ou fausses.

## Comment corriger

Corrigez le fichier JSON indiqué : sections existantes uniquement, une propriété par champ déclaré, types respectés (texte, nombre, `{ src, alt }` pour une image, `{ kind, href }` pour un lien).

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-201` au-dessus de la ligne, ou `/* openflow-disable OF-201 */` pour tout le fichier. Expliquez pourquoi en commentaire.

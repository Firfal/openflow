# OF-101 — Texte visible écrit en dur dans une section

- Gravité : **erreur**
- Niveau de contrôle : rapide (à chaque modification)
- Statut : appliquée

## Pourquoi

Le propriétaire du site ne peut modifier que ce qui passe par un champ. Un texte écrit en dur dans le JSX est invisible dans l'admin : il faudra rappeler un développeur pour le changer.

## Comment corriger

Créez un champ (`type: "text"`, `contentEditable: true` pour un titre ou un bouton ; `"textarea"` ou `"richtext"` pour un paragraphe), mettez le texte actuel dans `defaultProps`, puis affichez `{nomDuChamp}` à la place du texte.

## À éviter

```tsx
render: () => <h2>Nos services</h2>
```

## À faire

```tsx
fields: { title: { type: "text", contentEditable: true } },
defaultProps: { title: "Nos services" },
render: ({ title }) => <h2>{title}</h2>
```

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-101` au-dessus de la ligne, ou `/* openflow-disable OF-101 */` pour tout le fichier. Expliquez pourquoi en commentaire.

# OF-104 — Champ déclaré mais jamais affiché

- Gravité : **erreur**
- Niveau de contrôle : rendu (fin de tâche)
- Statut : appliquée

## Pourquoi

Un champ que le rendu n'utilise pas trompe le propriétaire : il modifie une valeur et rien ne change sur le site.

## Comment corriger

Affichez le champ dans `render` ou supprimez-le de `fields` et de `defaultProps`.

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-104` au-dessus de la ligne, ou `/* openflow-disable OF-104 */` pour tout le fichier. Expliquez pourquoi en commentaire.

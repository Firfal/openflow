# OF-408 — Formulaire non déclaré aux assistants IA

- Gravité : **avertissement**
- Niveau de contrôle : build (avant livraison)
- Statut : appliquée

## Pourquoi

Les formulaires déclarés avec l'API déclarative de WebMCP (`toolname`, `tooldescription`) peuvent être remplis proprement par l'assistant IA du visiteur, qui lui demande confirmation avant l'envoi.

## Comment corriger

Affichez le formulaire avec `<OpenFlowForm>` de `@openflow/next/forms` (déclaration automatique), ou ajoutez `toolname` et `tooldescription` au `<form>` et `toolparamdescription` à chaque champ.

## À éviter

```tsx
<form action="/devis">…</form>
```

## À faire

```tsx
<OpenFlowForm formId={id} fields={formFields} toolDescription="Demander un devis" />
```

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-408` au-dessus de la ligne, ou `/* openflow-disable OF-408 */` pour tout le fichier. Expliquez pourquoi en commentaire.

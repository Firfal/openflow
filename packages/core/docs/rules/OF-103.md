# OF-103 — Lien écrit en dur au lieu d'un champ lien

- Gravité : **erreur**
- Niveau de contrôle : rapide (à chaque modification)
- Statut : appliquée

## Pourquoi

Les destinations de liens (pages, e-mail, téléphone, réseaux sociaux) changent. Un `href` fixe ne peut pas être modifié par le propriétaire et casse quand une page est renommée.

## Comment corriger

Déclarez `link: linkField({ label: "Lien" })` et affichez `<a {...linkProps(link)}>{label}</a>`. Les ancres internes (`href="#contact"`) et le lien vers l'accueil (`href="/"`) restent autorisés.

## À éviter

```tsx
<a href="/contact">Nous écrire</a>
```

## À faire

```tsx
fields: { cta: linkField(), ctaLabel: { type: "text", contentEditable: true } },
render: ({ cta, ctaLabel }) => <a {...linkProps(cta)}>{ctaLabel}</a>
```

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-103` au-dessus de la ligne, ou `/* openflow-disable OF-103 */` pour tout le fichier. Expliquez pourquoi en commentaire.

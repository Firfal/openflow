# OF-304 — Secret écrit dans le code

- Gravité : **erreur**
- Niveau de contrôle : rapide (à chaque modification)
- Statut : appliquée

## Pourquoi

Le code du site est archivé et déployé ; un secret dans le code finit sur Cloud Storage et parfois dans le navigateur.

## Comment corriger

Supprimez le secret, révoquez-le, et utilisez un secret Cloud Functions (`defineSecret`) côté serveur. La clé d'API web Firebase n'est pas un secret et reste autorisée.

## Désactiver ponctuellement

Uniquement si le signalement est un faux positif : `// openflow-disable-next-line OF-304` au-dessus de la ligne, ou `/* openflow-disable OF-304 */` pour tout le fichier. Expliquez pourquoi en commentaire.
